# Grant Justification Memo (invoice-to-grant mapping)
**Purpose:** Every invoice ships with a memo mapping the work to grant-allowable cost categories. This is the pricing differentiator — it turns "a consultant bill" into "a grant expense."

## Memo template (one page, attached to each invoice)

---
**Grant Justification Memo**
- Client: <Org> · Invoice #: <n> · Period: <date range> · Amount: <$>
- Service: <e.g., Compliance Office — Plus tier, Q3>
- Grant/award referenced: <Award name + ID + funder>
- Cost category: <e.g., Technology & Security / Indirect / Program Support — match funder's budget categories>
- **Grant nexus (2–4 sentences):** how this work directly supports the award's compliance obligations (e.g., "GSA CUI rule (effective Jan 2026) requires [Org] to evaluate systems processing CUI under Award #X; this engagement produces the required SSP, POA&M, and quarterly evidence.")
- **Allowability:** <cite funder budget guidance clause permitting security/tech costs; for NSGP/SLCGP cite cybersecurity line item>
- **Deliverables this period:** <list from the retainer>
- Prepared by: <human> — for questions: <contact>
---

## Allowability cheat-sheet
| Funding source | Cyber/security costs allowed? | Cite |
|---|---|---|
| Federal grants (general) | Yes as program support/indirect if directly supporting award | OMB Uniform Guidance 2 CFR 200 (necessary & reasonable) |
| FEMA NSGP (FY2026) | **Yes — up to $150K** incl. cybersecurity line items | grants.gov NSGP notice |
| CISA State & Local Cybersecurity Grant Program | Yes (~$1B program; nonprofits often eligible via state subawards) | CISA SLCGP guidance |
| Foundation grants | Varies — TA/tech budgets often explicit | Award letter budget |
| State contracts | Yes where security compliance is a contract term | Contract §security |

## Rules
- **Never misstate allowability.** If a funder's budget line doesn't cover the service, the memo says the cost goes to indirect/overhead or another grant — or we re-scope.
- Memo is written per-invoice by the human; agent drafts from a client's grant index (kept in client workspace).
- This memo is also the sales tool: show it in the pitch to make the $500–$2,500/mo price point feel grant-funded, not budget-breaking.
