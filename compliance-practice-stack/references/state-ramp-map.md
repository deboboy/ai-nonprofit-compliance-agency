# State RAMP Map (GovRAMP) — maintained quarterly
**Last updated:** July 2026
**Source:** govramp.org participating list, Captain Compliance state survey (Mar 17, 2026), Knox Systems RAMP guides (Jun 2026)

## How to read this map
- GovRAMP (ex-StateRAMP) is the SLED clearinghouse: one assessment → "passport" across participating governments. **Participation is agency-level, not always statewide** — always check the specific agency in a contract.
- For a nonprofit: relevance is (a) their *vendors* must be GovRAMP-verified for state contracts, and (b) the org may face flow-down NIST 800-53/171 clauses.

## Quarterly maintenance checklist
1. Pull `govramp.org/participating-government-organizations` — diff vs. last quarter.
2. Check RAMP-equivalent states for new legislation (search "state cloud security law 2026").
3. Note FedRAMP 20x interplay: states increasingly accept 20x authorizations as GovRAMP equivalents — update client guidance when confirmed.
4. Record changes in this file with a dated changelog line.
