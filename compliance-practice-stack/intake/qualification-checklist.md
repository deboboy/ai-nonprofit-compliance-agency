# Qualification Checklist (20-min discovery call)
**Purpose:** Confirm fit before spending assessment hours. Seven questions; if any of A1–A3 fail, refer out or nurture.

## A. Must-pass (all three)
- [ ] **A1 — Budget floor:** ≥ $1M annual budget (exception: grant-funded security line item ≥ $10K).
- [ ] **A2 — Funding at risk:** ≥ 2 active government/federal-pass-through grants, or 1 grant ≥ $200K, or funder questionnaire received in last 12 months.
- [ ] **A3 — Authority:** the person on the call can sign (ED, COO, CFO) or has a named buyer.

## B. Signals (2 of 4 preferred)
- [ ] B1 — Received a security questionnaire or attestation request in last 12 months
- [ ] B2 — A vendor they depend on (or they as vendor) is FedRAMP/GovRAMP/SOC 2-adjacent
- [ ] B3 — Data shared with schools, health systems, or state agencies (data-sharing agreements with security clauses)
- [ ] B4 — Insurance renewal flagged security gaps (cyber/D&O)

## C. Anti-persona checks (refer out if true)
- [ ] C1 — Budget > $50M (needs real vCISO; refer to generalist vCISO firms)
- [ ] C2 — All-volunteer, < $300K (no budget; point to CISA/TechSoup free resources — good will, future client)
- [ ] C3 — "We want paper compliance only" (liability risk; refer to software-only platforms)

## D. Fit decision
- [ ] **Fit** → offer $500 Funded-Security Review → assessment
- [ ] **Nurture** → newsletter + scorecard band 0–6 path
- [ ] **Refer out** → note referral target; add to partner network

## E. Capture for intake triage prompt (`prompts/01-intake-triage.md`)
Org name, sector, budget band, staff count, funder list, frameworks mentioned, data types, IT stack (M365/Google/CRM), current security owner, deadline/driver (funder letter? date?), authority + email.
