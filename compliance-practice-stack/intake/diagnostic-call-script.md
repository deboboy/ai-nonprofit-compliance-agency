# Diagnostic Call Script — "Funded-Security Review" ($500)
**Purpose:** 30-min paid diagnostic producing a 2-page finding. Filters tire-kickers, funds funnel, seeds the assessment.

## Structure (30 min)
1. **Context (5 min)** — org, funders, deadlines, what triggered the call. Ask: *"Which funder letter or contract clause brought you here?"* (This is the buying trigger — note it verbatim.)
2. **Funder inventory (5 min)** — list every grant/contract with dollar value and security terms. Use `references/funder-security-terms-decoder.md` to classify each clause.
3. **Stack & data walk (5 min)** — M365/Google? CRM? beneficiary data? CUI? Where does the money data live?
4. **Vendor check (5 min)** — top 5 vendors; quick lookup against `references/state-ramp-map.md` + FedRAMP marketplace + GovRAMP participating list. Note any unverified vendors (likely gap #1).
5. **The 2-page finding (8 min)** — present live: (a) frameworks that apply, (b) top 3 gaps, (c) funder risk (which award is exposed), (d) recommended next step = full Readiness Assessment ($3.5K–$6.5K).
6. **Close (2 min)** — *"The assessment produces the full report plus the funder-questionnaire pack and the 90-day plan. If we start this week, you have it before [funder deadline]."*

## Scripting rules
- Never say "you're non-compliant" — say "your exposure on [award X] is [Y]."
- Anchor price to grant value: *"This is 1–2% of one award."*
- If they can't name a trigger → they're tire-kicking → offer the scorecard and nurture.

## Deliverable
`assessments/diagnostic-2pager.md` (light version of the full report: applies frameworks + top gaps + next step only).
